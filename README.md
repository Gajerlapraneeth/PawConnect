# 🐾 PawConnect — Community Animal Feeding & Welfare Platform

PawConnect is a web-based platform designed to help communities coordinate street-animal feeding activities and report animals that need care or emergency assistance.

## 🌐 Live Website

**Visit PawConnect:** https://pawconnect-2l81.onrender.com

## ✨ Features

- User registration and login
- Community animal-feeding coordination
- Feeding task management
- Animal welfare and emergency reporting
- Online access to the application

## 🛠️ Technology Stack

- **Frontend:** Project web interface
- **Backend:** Java Spring Boot
- **Database:** Neon PostgreSQL
- **Deployment:** Render
- **Version Control:** GitHub
